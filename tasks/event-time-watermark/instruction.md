The telemetry aggregator at `/app/aggregator.py` was written as a quick batch job: it loads the whole event log into memory and falls over with out-of-memory errors, and it assumes events arrive in time order when they don't. Rewrite it as a streaming aggregator. Running `python3 /app/aggregator.py` should read `/app/data/events.log` one line at a time and write `/app/output.json`, holding peak memory (RSS) under 64 MB and relying only on the Python standard library.

Each non-blank line is one event, in the order it arrived. A line is valid only when it is a JSON object with exactly four fields: `ts` (whole seconds as an integer ≥ 0), `svc` (one of `auth`, `gateway`, `payment`), `status` (an integer from 100 to 599), and `latency_ms` (an integer from 0 to 1000). Since a Python bool is also an int, a `true` or `false` in any of the numeric fields makes the line malformed. Ignore whitespace-only lines; count every other line that isn't a valid event as malformed and skip it.

Events can arrive late, so keep a watermark equal to the highest `ts` seen so far. An event is late when it arrives more than 30 seconds behind the watermark — that is, when the watermark minus its `ts` exceeds 30 — and late events are dropped and counted on their own. The first event is never late. Every valid event that isn't late falls into the 60-second tumbling window that starts at `ts - (ts % 60)`.

Write `/app/output.json` as one JSON object with `processed_count` (the events you kept), `malformed_count`, `late_count`, and `windows`. `windows` maps each window's start second, written as a string such as `"1740"`, to that window's `count`, `error_rate`, and `p95_latency_ms`; include a window only if at least one event landed in it. `error_rate` is the fraction of the window's events with a `status` of 400 or more, to four decimals. `p95_latency_ms` is the nearest-rank 95th percentile of the window's latencies — sort them ascending and take the value at 1-based position `ceil(0.95 × count)` — to two decimals. Round halves up rather than to even.

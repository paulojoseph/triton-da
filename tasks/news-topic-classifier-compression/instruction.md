Under `/app/data/train.jsonl` is a labelled training set of newsgroup posts — one JSON object per line, each with a `text` field and an integer `label` from 0 to 19 for the topic (`/app/data/labels.json` maps each id to its newsgroup name). Train a topic classifier on it and save the trained model to `/app/model.pkl`.

The model is graded on a held-out set of posts from the same 20 newsgroups — the standard test split, the same distribution and not given to you. Two things must both hold: the model must reach **at least 0.68 accuracy** on that held-out set, and `/app/model.pkl` must be **at most 1 MiB** (1,048,576 bytes). The size limit is the hard part — a straightforward TF-IDF-plus-linear model runs well over ten megabytes, and just trimming the vocabulary by frequency gives up too much accuracy to clear the bar. scikit-learn, NumPy and SciPy are installed.

`/app/model.pkl` must be a pickled scikit-learn estimator or `Pipeline` whose `.predict(...)` accepts a list of raw post strings and returns their integer labels. It is loaded with a restricted unpickler that only admits numpy / scipy / scikit-learn classes (so it cannot run arbitrary code on load), and it is handed only the held-out texts — so build it from standard scikit-learn components and keep everything needed for inference inside that single pickle.
